# 画面一覧

| 画面名 | URL | ログインが必要か | 使えるロール | 表示するもの・できること |
|-|-|:-:|-|-|
| **来館者** | | | | |
| 館トップ | `/m/{museum:slug}` | 不要 | 誰でも | 館名、公開中の展示一覧、言語の切り替え（`?lang=`）。有料の館では料金と「音声ガイドを購入」ボタン（パスがあれば有効期限を表示） |
| 展示ページ | `/e/{exhibition:slug}` | 不要 | 誰でも | 展示名・説明・期間、作品一覧（並び順）、ガイド番号の入力欄、「最初から続けて再生」ボタン、言語の切り替え |
| 作品ページ | `/a/{artwork:slug}` | 不要 | 誰でも | 画像、作品名、作者、制作年。無料の館かパスがあるときは、解説文、音声プレーヤー、「ここから続けて再生」ボタンも表示する。パスが無いときは購入ボタンを出す。言語の切り替え |
| 連続再生 | `/e/{exhibition:slug}/play?from={artwork:slug}` | 不要 | 誰でも（有料の館はパスが必要） | 再生中の作品の画像・作品名・解説文、再生 / 一時停止、前後の作品へスキップ、作品一覧から選んで移動、最後まで聴いたら終了の表示 |
| 支払い完了 | `/passes/complete?session_id=...` | 不要 | 誰でも | 「購入が完了しました」、有効期限、館トップと連続再生へのリンク。キャンセル時は館トップに戻す |
| パスの再表示 | `/passes/{token}` | 不要 | 誰でも | 画面は持たない。購入完了メールの URL から開くとパスを Cookie に保存し、館トップへリダイレクトする |
| **館管理者** | | | | |
| ダッシュボード | `/dashboard` | 必要 | 館管理者 | 自館の展示・作品の件数、音声や翻訳が未登録の作品一覧、パスの販売数と売上合計 |
| 展示一覧 | `/exhibitions` | 必要 | 館管理者 | 自館の展示一覧（期間、公開状態）、新規作成・編集・削除へのリンク |
| 展示の作成・編集 | `/exhibitions/create`、`/exhibitions/{exhibition}/edit` | 必要 | 館管理者 | 期間、公開状態、言語ごとの展示名・説明の入力 |
| 作品一覧 | `/exhibitions/{exhibition}/artworks` | 必要 | 館管理者 | 展示内の作品一覧（並び順、ガイド番号、公開状態、音声の有無）、並び順の変更 |
| 作品の作成・編集 | `/exhibitions/{exhibition}/artworks/create`、`/artworks/{artwork}/edit` | 必要 | 館管理者 | 作者、制作年、ガイド番号、並び順、公開状態、画像のアップロード、言語ごとの作品名・解説文 |
| 音声の管理 | `/artworks/{artwork}/edit`（作品編集画面の中） | 必要 | 館管理者 | 言語ごとの音声のアップロード・差し替え・削除と試聴 |
| QR コード | `/artworks/{artwork}/qr` | 必要 | 館管理者 | 作品の QR コード（SVG）と作品ページの URL、ダウンロード |
| QR 印刷用ページ | `/exhibitions/{exhibition}/qr` | 必要 | 館管理者 | 展示内の全作品の QR コードを、作品名とガイド番号つきで印刷用に並べる |
| 館の設定（料金） | `/museum/settings` | 必要 | 館管理者 | 音声ガイド料金の設定（0円なら無料） |
| **プラットフォーム管理者** | | | | |
| 館一覧 | `/admin/museums` | 必要 | 管理者 | 全館の一覧（館名、稼働 / 停止、料金、館管理者の人数）、停止・再開 |
| 館の作成・編集 | `/admin/museums/create`、`/admin/museums/{museum}/edit` | 必要 | 管理者 | 館名、公開用 slug、対応言語、既定言語の入力 |
| 館管理者の一覧 | `/admin/museums/{museum}/staff` | 必要 | 管理者 | その館の館管理者一覧 |
| 館管理者の発行 | `/admin/museums/{museum}/staff/create` | 必要 | 管理者 | 名前とメールアドレスを入力してアカウントを発行し、招待メールを送る |
| **認証・共通** | | | | |
| ログイン | `/login` | 不要 | 館管理者・管理者 | メールアドレスとパスワードでログインし、ロールに応じた画面へ進む |
| パスワードリセットの申し込み | `/forgot-password` | 不要 | 館管理者・管理者 | メールアドレスを入力し、再設定メールを送る |
| パスワード再設定 | `/reset-password/{token}` | 不要 | 館管理者・管理者 | 新しいパスワードを設定する（招待メールからのパスワード設定もこの画面を使う） |

- 画面を持たないルート: 音声の配信（`/a/{slug}/audio`）、購入ボタンの送信先（POST）、Stripe Webhook（`POST /stripe/webhook`）
- Stripe の決済ページはアプリの外。プロフィールやパスワード変更（`/settings/...`）はスターターキットの既存画面を使う
- 管理画面の URL は、ログインが必要で認可で守るため連番の ID を使う
