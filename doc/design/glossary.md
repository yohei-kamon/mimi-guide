# 用語集

> テーブルとカラムの詳細は [database.md](database.md)、画面と URL は [screens.md](screens.md) を参照。

| 用語 | 英名・テーブル | 意味 |
|-|-|-|
| 館 | Museum / `museums` | プラットフォームに参加する美術館・博物館。データは館ごとに分ける。対応言語と既定言語を持つ |
| プラットフォーム管理者 | `admin` | 館の登録・停止・館管理者アカウントの発行を行う運営側ユーザー |
| 館管理者 | `staff` | 自館の展示・作品・音声を登録・更新するユーザー。所属する館は1つ |
| 来館者 | ゲスト | ログインせずに QR コードやガイド番号から音声ガイドを聴く人。ユーザーとしては保存しない |
| 展示 | Exhibition / `exhibitions` | 館の中の展示単位（常設展・企画展など）。期間と公開状態を持つ |
| 作品 | Artwork / `artworks` | 展示に含まれる1点の作品・資料。所属する展示は1つだけ（`exhibition_id` を持つ）。作者、制作年、画像を持つ（作者名と制作年は言語で書き方が変わるため翻訳側に持つ） |
| 解説文 | `description` | 作品ページに表示するテキスト。音声の読み上げ原稿も兼ねる。言語ごとに持つ |
| 言語 | `locale` | `ja`、`en` などの言語コード。来館者は館の対応言語から選び、未選択なら館の既定言語で表示する |
| 翻訳 | 〜Translation / `〜_translations` | 館名・展示名・作品名・解説文など、言語で変わる文言を言語ごとに保存したもの。翻訳が無い言語は既定言語で表示する |
| 音声ガイド | AudioGuide / `audio_guides` | 作品に紐づく音声ファイル。1作品につき1言語1件まで（`artwork_id` と `locale` の組で重複しない） |
| ガイド番号 | `guide_number` | 館内の掲示に書く番号。同じ展示の中では重複しない（`exhibition_id` と `guide_number` の組で一意）。別の展示とは同じ番号を使ってよいので、来館者は展示を選んでから番号を入力する |
| QR コード | ─ | 作品ページの URL を表すコード。URL は推測されにくい公開用 ID（slug）で作り、言語は含めない |
| 公開状態 | `status` | 下書き / 公開 / 非公開。来館者に見えるのは「公開」だけ |
| 料金 | `guide_price` | 館ごとの音声ガイド料金。円の整数で `museums.guide_price` に持つ。0 なら無料で、パスは不要 |
| ガイドパス | GuidePass / `guide_passes` | 来館者が有料の館で音声ガイド料金を払うと発行される利用権。会員登録なしで買えるため、ユーザーではなくランダムなトークンで識別し、ブラウザの Cookie で持つ。館単位で、支払いから 24 時間有効。状態は `pending` / `paid`。購入時の金額を `amount` に保存し、後から料金が変わっても影響しない。有料の館では解説文と音声にパスが必要 |
